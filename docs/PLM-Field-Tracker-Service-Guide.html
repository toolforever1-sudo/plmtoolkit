Configuration

Before first run, edit config/application-prod.properties with your database connection details:

# Database
spring.datasource.url=jdbc:oracle:thin:@//your-db-host:1521/your-service-name
spring.datasource.username=your_db_user
spring.datasource.password=your_db_password

# Server port (default 8080)
server.port=8080

Starting the Service

Option 1: Foreground (see logs in terminal)

java -jar plm-field-tracker-1.0.0.jar \
  --spring.config.additional-location=config/application-prod.properties

Option 2: Background (Linux/Mac)

nohup java -jar plm-field-tracker-1.0.0.jar \
  --spring.config.additional-location=config/application-prod.properties \
  > plm-tracker.log 2>&1 &

# Save the process ID for later
echo $! > plm-tracker.pid

Option 3: Background (Windows)

start /B java -jar plm-field-tracker-1.0.0.jar ^
  --spring.config.additional-location=config\application-prod.properties ^
  > plm-tracker.log 2>&1
Note: The application takes about 5-10 seconds to start. Look for Started Application in X seconds in the log output to confirm it's ready.

Verify the Service is Running

Open a browser and go to:

http://localhost:8080

Or from the command line:

curl http://localhost:8080/api/changes?field=Description&days=1

A JSON response confirms the service is up and connected to the database.

Stopping the Service

If running in foreground

Press Ctrl+C in the terminal.

If running in background (Linux/Mac)

# Using the saved PID file
kill $(cat plm-tracker.pid)

# Or find and kill the process
ps aux | grep plm-field-tracker
kill <PID>

If running in background (Windows)

REM Find the Java process
tasklist | findstr java

REM Kill by PID
taskkill /PID <PID> /F

Changing the Port

Add this to your properties file or pass it as a command-line argument:

# In application-prod.properties
server.port=9090

# Or as a command-line argument
java -jar plm-field-tracker-1.0.0.jar --server.port=9090
