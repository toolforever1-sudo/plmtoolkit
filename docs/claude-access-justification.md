Hi Pete,

**The ask:** a security waiver plus Claude Pro Max access ($100/user/month) for the two people building the Agile Toolkit — Vikas Singh (design & maintenance) and Vikas Jindal (development & maintenance). Total: $200/month. Everything below is what that access has already produced.

**Why we built it.** Agile PLM is end-of-life — Oracle hasn't enhanced it in over a decade, and no migration is planned for several years. Rather than wait, Agile IT used AI-assisted development to close the gap ourselves: a basic AI-generated web app in April 2026 has grown into the **Agile Toolkit**, a modern UI on top of Agile.

**What it is today** — three months in, with zero additional headcount or budget:

- **22 live modules**, including bulk Item/BOM/Change reporting (seconds instead of days), a live ECN KPI dashboard, and an IMS Dashboard that writes back to Agile and streamlines DRR/DCO document reviews.
- **~135,000 lines of code** with 250 automated tests, and **340+ shipped updates** since April — requests typically go from ask to production in days.
- **License-independent:** Toolkit users don't need an Agile seat unless they create or approve changes — a direct licensing saving.
- **PLM-agnostic:** built on core PLM principles, so it can be re-pointed at a future PLM system without changing the user experience.

**What's next:** a Single/Sole Source dashboard (real-time sourcing decisions, no email chains), the SWIFT framework (streamlined change submission, execution, review, and flow), a CCB Matrix redesign, and external-system integrations. The Toolkit is R.E.S.E.T. in practice: reimagined workflows, an empowered org, simpler daily work, and measurable transformation at zero added cost.

**Why Claude specifically.** All of the above was built with Claude Pro Max — funded out of the team's own pockets, after corporate-approved models proved too limited for work at this scale. Claude is the industry standard for AI-assisted development: it handles our full codebase in one session, and its design and mockup output turns days of UI work into hours. SanDisk security currently blocks Claude for non-IT teams, which is why we need the waiver alongside the licenses.

**Bottom line:** $2,400/year against the team-weeks already being saved every month — and a working bridge off a retiring PLM platform.
