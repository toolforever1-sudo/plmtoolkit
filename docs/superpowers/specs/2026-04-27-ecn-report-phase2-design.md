# ECN Report Tab — Phase 2 Design

## Overview

Standalone ECN Report tab with an interactive dashboard mirroring the Email Format sheet from the SLA Excel template. Features editable SLA targets with named profiles, instant client-side recalculation, server-side persistence, branded email delivery with chart images, and role-based access control.

Phase 1 (utility entry in Reports tab) remains as a fallback.

## Architecture — Hybrid Split

- **Python** — data acquisition from Oracle + Excel generation + chart PNG generation for email
- **Java (Spring Boot)** — API layer, SLA profile management, access control, email assembly, JSON serving
- **Browser (Chart.js)** — interactive dashboard with instant recalculation when targets change
- **Email** — static HTML with matplotlib-generated chart PNGs + Excel attachment

### Data Flow

1. User clicks "Run" → `POST /api/ecn-report/run`
2. Backend spawns Python: `ecn_report_generator.py --config ... --output ... --json-output ecn_data.json --no-email`
3. Python produces: `ECN_Report.xlsx` + `ecn_data.json` (row-level ECN data + baseline targets from Matrix sheet)
4. Frontend fetches `GET /api/ecn-report/data` → receives JSON with ECN rows + active SLA profile merged
5. Dashboard renders KPI tiles + Chart.js charts
6. User edits a target → client-side instant recalculation of % on Target, KPI tiles, charts
7. User clicks "Save & Recalculate" → `POST /api/ecn-report/recalculate` → server persists profile, recomputes authoritative stats, regenerates Excel
8. User clicks "Send Email" → `POST /api/ecn-report/email` → Python generates chart PNGs → backend assembles HTML + attaches Excel → sends via EmailService

## Data Model

```json
{
  "generatedAt": "2026-04-27T10:30:00",
  "dateRange": { "start": "2026-01-01", "end": "2026-04-27" },
  "ecns": [
    {
      "number": "ECN-12345",
      "priority": "Standard",
      "requestClassification": "BOM/Component Update",
      "requestSubclass": "Additional Plant Extension",
      "ecnClassification": "General ECNs",
      "changeType": "Part/BOM Change",
      "productLine": "1024 - MicroSD",
      "productTeam": "CS",
      "actualDays": 7,
      "status": "Completed",
      "createdDate": "2026-02-10",
      "completedDate": "2026-02-17",
      "originator": "Zhu, Peter"
    }
  ],
  "baselineTargets": {
    "BOM/Component Update|Additional Plant Extension": { "standard": 10, "urgent": 6 },
    "PDR Request|PDR-New Channel SKU Release": { "standard": 15, "urgent": 10 }

}
```

Keys in `baselineTargets` use the format `"Request Classification|Request Subclass"` matching the Matrix sheet.

### sla-profiles.json

```json
{
  "profiles": [
    {
      "id": "uuid-1",
      "name": "Q2 2026 Adjusted Targets",
      "createdBy": "vikas.jindal",
      "createdAt": "2026-04-27T10:00:00",
      "active": true,
      "overrides": {
        "BOM/Component Update|Additional Plant Extension": { "standard": 8, "urgent": 5 }
      }
    }
  ],
  "editors": ["jimmy.sessumes", "vikas.singh"]
}
```

- Profiles store only deltas from baseline. At most one profile has `"active": true`.
- If no profile is active, baseline targets from the Excel template apply.

### annotations.json

```json
{
  "ECN-12345": {
    "note": "Follow up with owner re: approval delay",
    "editedBy": "vikas.jindal",
    "editedAt": "2026-04-27T11:00:00",
    "teamOverride": "ESSD",
    "classificationOverride": "Dedicated Process ECNs"
  }
}
```

Metadata corrections (team, classification dropdowns) and free-text notes, keyed by ECN number.

### distribution-list.json

```json
{
  "recipients": [
    { "name": "Jimmy Sessumes", "email": "jimmy.sessumes@wdc.com" },
    { "name": "Vikas Singh", "email": "vikas.singh@wdc.com" }
```

### Data Table

Full ECN row-level table:

| ECN# | Priority | Req Classification | Subclass | ECN Classification | Change Type | Product Team | Actual Days | Target Days | On Target | Status | Originator | Notes |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

- **Editable columns:** Product Team (dropdown), ECN Classification (dropdown), Notes (free text)
- **On Target:** green check if actual <= target, red X otherwise — updates instantly when targets change
- **Target Days:** reflects active profile overrides
- Sortable, filterable, paginated (~4,000 rows)
- `[Export Table]` downloads current view as CSV
- Click a chart bar to filter table to those ECNs

## Charts

### In-tab (Chart.js — interactive)

- **Volume panels (left column):** stacked bar chart — Standard vs Urgent per month
- **Cycle Time panels (center/right):** dual-axis line chart — Avg Days (left axis, solid line) + % on Target (right axis, dashed line), with target threshold as horizontal reference line
- **POM panel:** grouped bar chart — 3 months side by side
- Hover for tooltips, click bar to filter data table
- Charts update instantly on SLA target changes
- Trend window: 3 most recent calendar months from the report's date range

### In email (Python matplotlib — static PNGs)

- Same chart types, sized 280x160px per panel (fits 3-across in 600px email)
- Clean axis labels, app color palette: `#4a6fa5` primary, `#1F8A4C` success, `#B8342B` error
- Generated on demand via `--charts-only` flag when email is sent

## Access Control

### Roles

- **Admin** — full access: run, promote SLA, send email, manage editors, manage distribution list
- **Editor** — named users (initially: Jimmy Sessumes, Vikas Singh): run, promote SLA, send email, save profiles
- **Viewer** — any authenticated user: view tab, personal what-if profiles, add annotations

### Editor Management

- Admins see `[Manage Editors]` button in toolbar
- Modal: list of current editors with `[x Remove]`, text input to add by username with `[+ Add]`
- Stored in `sla-profiles.json` under `"editors"` array
- Backend enforces role checks on all endpoints

## Email Workflow

1. Editor/admin clicks `[Send Email]` → modal opens
2. **Recipients panel:** pre-populated from distribution-list.json. Sender can remove/add ad-hoc addresses. Changes are for this send only. `[Edit Default List]` link (admin) opens persistent list editor.
3. **Preview panel:** rendered HTML preview using active SLA profile's KPIs
4. **Subject line:** auto-generated `"ECN Report -- Q1 2026 YTD (as of Apr 27, 2026)"` — editable
5. `[Send]` → `POST /api/ecn-report/email` with `{ recipients, subject, profileId }`
6. Backend calls Python: `--charts-only --profile <id> --output output/charts/` → produces 7 PNGs
7. Backend assembles branded HTML (CLAUDE.md email guidelines: table-based, 600px, `#2c3e50` headers, IBM Plex fonts, dark mode, KPI tiles)
8. Chart PNGs embedded as CID inline attachments, `ECN_Report.xlsx` as file attachment
9. Sent via existing EmailService
